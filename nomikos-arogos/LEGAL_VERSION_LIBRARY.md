# Ιστορικές εκδόσεις νόμων και μεταβατικές διατάξεις

## Στόχος

Ο Νομικός Αρωγός **δεν πρέπει να επιλέγει αυτομάτως τη νεότερη διατύπωση μιας διάταξης**. Η χρονική ισχύς εξετάζεται βάσει του κρίσιμου γεγονότος (π.χ. θάνατος, τέλεση πράξης, κατάρτιση σύμβασης, κατάθεση ή επίδοση) και της **εγκριμένης πηγής**. Η δημοσίευση, η έναρξη ισχύος και η εφαρμογή σε γεγονότα συγκεκριμένης ημερομηνίας είναι διαφορετικά μεγέθη.

Η νέα υποδομή είναι **γενικευμένη αλλά όχι ακόμη πλήρης νομική βιβλιοθήκη**. Χωρίς εγκεκριμένους κανόνες και πραγματικά ιστορικά κείμενα, δεν ισχυριζόμαστε ότι υπάρχει πλήρης κάλυψη όλων των νόμων.

## Δύο πίνακες με ανθρώπινη έγκριση

- `legal_transition_rules`: ζήτημα/θεματική, τομέας δικαίου, είδος κρίσιμου γεγονότος, ενδεικτικές λέξεις αντιστοίχισης, ακριβής πρωτογενής νομική πηγή, εξαιρέσεις, κατάσταση ελέγχου.
- `legal_text_versions`: ακριβές κείμενο, νομοθετική παραπομπή, ημερομηνία δημοσίευσης, `applicable_from` και `applicable_until` (τελευταία *μη* συμπεριλαμβανόμενη), πηγή, SHA-256 περιεχομένου, πιθανή αναδρομικότητα και ρητή νομική βάση της.
- `legal_history_audit`: καταγραφή εγκρίσεων/απορρίψεων, ελεγκτή και digest.

Η εισαγωγή δημιουργεί εγγραφές **pending**, όχι approved. Η επίσημη ηλεκτρονική διεύθυνση είναι αναγκαία, όχι επαρκής απόδειξη ότι το περιεχόμενο είναι νομικά ορθό. Η έγκριση προϋποθέτει ανάγνωση/έλεγχο της πραγματικής διατύπωσης, χρονικής ισχύος, μεταβατικών και πιθανής αναδρομικότητας από νομικό.

## Έλεγχοι πριν το μοντέλο

1. Ανιχνεύεται με εγκεκριμένους, χειροκίνητα ορισμένους κανόνες το θέμα και **η σχετική ημερομηνία γεγονότος**.
2. Αν λείπει ημερομηνία, υπάρχουν αντιφάσεις, επικαλύπτονται εκδόσεις, λείπει εγκεκριμένο κείμενο ή έχει δηλωθεί ειδική εξαίρεση, η ανάλυση **μπλοκάρεται** και αναφέρεται ο λόγος.
3. Όταν έχει επιλεγεί μία ακριβώς ιστορική έκδοση, οι παλιές/νεότερες ανεξέλεγκτες εκδόσεις της ίδιας διάταξης αφαιρούνται από τις πηγές που βλέπει ο Source Checker και ο συνθετικός agent.
4. Το μοντέλο λαμβάνει το εγκεκριμένο κείμενο, τις ημερομηνίες εφαρμογής και την πρωτογενή πηγή. Η τελική απάντηση υποχρεούται να αναφέρει την ακριβή ιστορική παραπομπή, αλλιώς αποκρύπτεται. Η ανεξάρτητη επαλήθευση εξακολουθεί να απαιτείται.
5. Η ήδη ειδική προστασία του ν. 5303/2026 (αποποίηση κληρονομιάς και άρθρα 1857/1855 ΑΚ) παραμένει ανέπαφη και προηγείται για τις σχετικές υποθέσεις. Ο γενικός μηχανισμός καλύπτει **άλλες εγκεκριμένες θεματικές**. Δεν υπάρχουν ακόμη γενικές έγκυρες μεταβατικές εγγραφές στην παραγωγική βάση.

Η αποτυχία αντιστοίχισης σε εγκεκριμένο κανόνα `not_covered` δεν αποδεικνύει ότι «δεν άλλαξε ο νόμος»: μόνο ότι **η συγκεκριμένη ιστορική περίπτωση δεν καλύπτεται από το ελεγμένο μητρώο**. Η υφιστάμενη προειδοποίηση επικαιρότητας παραμένει απαραίτητη.

## Διαχείριση εγγραφών — μόνο στο Railway backend

Από τον κατάλογο `nomikos-arogos/backend`:

```bash
npm run law-history -- --list
npm run law-history -- --import ./local-private-rule.json
npm run law-history -- --approve-rule case-rule-1 --reviewer legal-reviewer-id
npm run law-history -- --approve-version article-version-1 --reviewer legal-reviewer-id
```

Μην τοποθετείτε δικαστικά ή προσωπικά έγγραφα στα δημόσια repository manifests. Η δημιουργία εγγραφής `pending` δεν την καθιστά διαθέσιμη στη μηχανή αναζήτησης. Ο χειριστής του εργαλείου CLI **δεν πιστοποιείται αυτόματα ως δικηγόρος** και ο νομικός έλεγχος πρέπει να είναι πραγματικός.

Για τη μορφή του JSON βλέπε τα υποχρεωτικά πεδία του `legalHistoryAdmin.js`. Η εισαγωγή δεν αντικαθιστά ήδη αποθηκευμένες εγγραφές ώστε να μη μεταβάλλεται σιωπηρά η επαληθευμένη ιστορική έκδοση. Μεταβολές απαιτούν νέο αναγνωριστικό έκδοσης και νέο έλεγχο.

Δημοσίευση: **27 Φεβρουαρίου 2025**. Α1 Πολιτικό Τμήμα. Η απόφαση ασχολείται με το έννομο συμφέρον για αναίρεση από τον νικήσαντα διάδικο, το δεδικασμένο και διαδικαστικά ζητήματα στο πλαίσιο εργασιακής διαφοράς. **Δεν αποτελεί άμεση κρίση περί πλάνης και ακύρωσης αποποίησης κληρονομιάς.** Μπορεί να είναι χρήσιμη για συγκεκριμένο επιμέρους δικονομικό ζήτημα μετά από σύγκριση πραγματικών περιστατικών· ο agent δεν πρέπει να τη μετατρέπει σε αυτοματοποιημένη «υποστηρικτική κληρονομική νομολογία».

Η απόφαση προστέθηκε **μόνο ως υποψήφια** στο `decisions.json`. Χρειάζεται πραγματική λήψη του πλήρους σώματος και έγκριση στο Railway πριν να καταστεί αναζητήσιμη· τα κουμπιά τρίτων υπηρεσιών AI στον ιστότοπο του Αρείου Πάγου **δεν αποτελούν επίσημα επιβεβαιωμένες περιλήψεις**.
