# Άρειος Πάγος — όροι χρήσης νομολογίας στον Νομικό Αρωγό

Πρωτογενής πηγή: https://www.areiospagos.gr/nomologia/apofaseis.asp

## Δεσμεύσεις εισαγωγής

1. Χρησιμοποιούνται μόνο τα αναρτημένα κείμενα αποφάσεων, όχι η λημματογράφηση, τα ευρετήρια ή οι περιλήψεις του ιστότοπου. Η μηχανή απομονώνει το κυρίως σώμα από την επικεφαλίδα «Αριθμός Ν/ΕΕΕΕ».
2. Δεν γίνεται αλλοίωση ή διαστρέβλωση του περιεχομένου. Οι μορφοποιητικές αφαιρέσεις HTML και ο κατακερματισμός για αναζήτηση δεν υποκαθιστούν το πλήρες αυθεντικό κείμενο. Οι απαντήσεις της εφαρμογής είναι *ερμηνείες* και πρέπει να ελέγχονται σε αντιπαραβολή με την πρωτογενή πηγή.
3. Κάθε ανακτημένο απόσπασμα έχει **επίσημο URL** και **ημερομηνία δημοσίευσης της απόφασης**. Η δεύτερη διαβάζεται από τη ρήτρα «ΔΗΜΟΣΙΕΥΘΗΚΕ», όχι από τη ρήτρα «ΚΡΙΘΗΚΕ», το έτος στον αριθμό απόφασης ή την ημερομηνία ανάρτησης/ευρετηρίασης.
4. Αν η ημερομηνία δεν μπορεί να εξακριβωθεί με ασφάλεια, η εισαγωγή απορρίπτεται αντί να επινοηθεί ημερομηνία.
5. Κάθε απόφαση εισάγεται σε κατάσταση `pending`· η βάση RAG δεν την αναζητά μέχρι να ελεγχθεί και εγκριθεί από άνθρωπο. Η έγκριση πρέπει να περιλαμβάνει έλεγχο ορθότητας κειμένου, απόφασης/τμήματος/δημοσίευσης, τυχόν αστοχιών ανωνυμοποίησης και νομικής συνάφειας.
6. Η οθόνη αναφέρει ρητά ότι τα ανωνυμοποιημένα ηλεκτρονικά κείμενα έχουν **πληροφοριακό χαρακτήρα και δεν αποτελούν νόμιμα και ακριβή αντίγραφα**.
7. Δεν χρησιμοποιείται μηχανισμός μαζικής αντιγραφής/δημοσίευσης της ευρετηρίασης, ταξινομίας ή των περιλήψεων του δικαστηρίου.

## Τρεις εξειδικευμένοι, ντετερμινιστικοί agents

- `DecisionBodyAgent`: διακρίνει την απόφαση από σελίδα αποτελεσμάτων ή περίληψη.
- `PublicationDateAgent`: εντοπίζει και επικυρώνει την ημερομηνία δημοσίευσης.
- `ProvenanceAgent`: απαιτεί πηγή, ημερομηνία και αριθμό πριν την εισαγωγή.

Οι agents δεν είναι νομικοί, δεν προσφέρουν πιστοποίηση γνησιότητας και δεν αναλαμβάνουν δικονομικές πράξεις. Τα regex τους πρέπει να επιβεβαιώνονται με επίσημα κείμενα διαφορετικών ετών/τμημάτων. Κάθε απόφαση που δεν ταιριάζει στο γνωστό πρότυπο χρειάζεται χειροκίνητο έλεγχο.

## Εκκρεμή πριν την παραγωγή

- Πραγματική δοκιμή φόρτωσης του επίσημου HTML από Railway, τήρηση ευγενικών ρυθμών πρόσβασης.
- Δειγματοληπτικός έλεγχος των 22 πρώτων αποφάσεων με επίσημα στοιχεία, χωρίς αυτόματη έγκρισή τους.
- Επαλήθευση χρήσης σε συνάρτηση με τυχόν νέους όρους του Αρείου Πάγου και πολιτική προστασίας δεδομένων.
- Αν απαιτηθούν νόμιμα και ακριβή αντίγραφα για δικαστική χρήση, αυτά λαμβάνονται από την αρμόδια υπηρεσία.

## Εισαγωγή μεμονωμένης απόφασης

Μέσα στο περιβάλλον διαχείρισης (Railway backend), μετά την αναζήτηση στον επίσημο ιστότοπο, μπορεί να εισαχθεί **ένας συγκεκριμένος επίσημος σύνδεσμος** με:

```bash
npm run decisions -- --url 'https://www.areiospagos.gr/nomologia/apofaseis_DISPLAY.asp?cd=EXAMPLE&apof=1497_2023' --area civil
```

Ο σύνδεσμος του παραδείγματος δεν αποτελεί από μόνος του αποδεικτικό ελέγχου. Το πρόγραμμα επιβεβαιώνει το URL, τον αριθμό απόφασης, το κύριο σώμα και την ημερομηνία δημοσίευσης. Η απόφαση **δεν γίνεται διαθέσιμη στη RAG** προτού ελεγχθεί και εγκριθεί. Η επιλογή δεν μαζεύει τη λημματογράφηση, τα ευρετήρια ή τις περιλήψεις του ιστότοπου.

## REG — JSON Source Adapter (προτεινόμενη, ελεγχόμενη λειτουργία)

Ο `REG` (`backend/regAgent.js`) είναι ντετερμινιστικός μηχανισμός ανάκτησης **μίας συγκεκριμένης** απόφασης. Δεν είναι crawler και δεν αναζητά ή αντιγράφει ευρετήρια/περιλήψεις. Αποδέχεται τον επίσημο σύνδεσμο `apofaseis_DISPLAY.asp?cd=…&apof=…`, τον επίσημο σύνδεσμο `apofasi_ai_v2.asp?cd=…` ή τον αντίστοιχο Google Translate **μόνο ως είσοδο**. Ο σύνδεσμος Google Translate δεν χρησιμοποιείται για ανάκτηση κειμένου ούτε ως πηγή παραπομπής.

1. Από το `cd` επιχειρεί μία ανάκτηση του **ελληνικού** `document_text` από `https://www.areiospagos.gr/nomologia/apofasi_ai_v2.asp`.
2. Ελέγχει `status=success`, ακριβή ταυτότητα `case_id`, `court=Areios Pagos`, επικεφαλίδα `Αριθμός N/YYYY`, πλήρες σκεπτικό και τη ρήτρα **ΔΗΜΟΣΙΕΥΘΗΚΕ**. Ασυμφωνία ταυτότητας απορρίπτεται χωρίς fallback.
3. Σε τεχνική αστοχία ή μη αξιοποιήσιμη απόκριση JSON, επιτρέπεται fallback μόνο στην **επίσημη HTML σελίδα της ίδιας συγκεκριμένης απόφασης**, εφόσον η είσοδος περιέχει ήδη `apof=N_YYYY`. Η HTML υπόκειται στους ίδιους ελέγχους. Για `cd`-only είσοδο δεν επιχειρείται εικασία του `apof` σε περίπτωση αστοχίας.
4. Επιβάλλονται allowlist HTTPS host/path, απόρριψη credentials/άγνωστων hosts/διπλών παραμέτρων ταυτότητας, timeout, όριο 2 MB, χωρίς αυτόματη ανακατεύθυνση σε άλλο domain.
5. Η αναφορά σε άλλες αποφάσεις ή διατάξεις μέσα στο κείμενο είναι μόνο **μη επαληθευμένη ένδειξη**. Δεν θεωρείται ξεχωριστή απόφαση, νομική αυθεντία ή εγκεκριμένη RAG πηγή χωρίς νέα ανεξάρτητη ανάκτηση και ανθρώπινο έλεγχο.
6. Η εισαγωγή εξακολουθεί να δημιουργεί αποκλειστικά `review_status=pending`. **Καμία αυτόματη έγκριση** ή αλλαγή στον κανόνα `approved` της RAG.

Παράδειγμα μίας απόφασης:

```bash
npm run decisions -- --url 'https://www.areiospagos.gr/nomologia/apofasi_ai_v2.asp?cd=L6GPBiDNyTnGk6UqHybZD3rXLoPbAV' --area civil
```

Το `apofasi_ai_v2.asp` δεν έχει επιβεβαιωθεί ως δημόσια τεκμηριωμένο/σταθερό API. Η διαθεσιμότητα, η επιτρεπόμενη αυτοματοποίηση και η πραγματική συμπεριφορά από Railway χρειάζονται ανεξάρτητη επαλήθευση πριν από παραγωγική χρήση. Τα offline regression tests δεν αποδεικνύουν live πρόσβαση, εγκυρότητα δικαστικού αντιγράφου ή νομική ορθότητα.
